### Changed
- Knowledge pages: one editor on CodeMirror 6 - a page opens ready to type on a computer, Markdown marks (**, _, #, links) show only at the cursor, tables stay formatted (click a cell, Tab = next cell), checkboxes tick and links open on the first click; the Read/Edit switch and Source/Preview are gone, "Edit as Markdown" and "Read only" are in the page's "…" menu; on a phone the page is read first and the pen opens the same editor (#4052).
- Document sidebar: "To review" is one compact line with "Checked" beside it (below on a phone); with a stack the box asks "No stack" / "Split stack…" first; due date and task are one line with a single "Task…" button (New task / Link with a task…); Show · Download · More… and a red trash icon fit one line (#4469).
- List fields are added, changed and deleted at once: the dialog closes, the column shows or goes immediately, the server follows and an error takes it back with its message; each step can be undone (#4658).
- Dependency check: `tools/pins.py --osv` also checks Mermaid, KaTeX and the DOMPurify bundled in Mermaid (known unreachable holes listed with a reason in `tools/pins_osv_ignore.json`); pip is removed from the app and embed images (#4169).

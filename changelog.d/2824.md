Package 2.557 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).
### Added
- Server agents (#4670): a third kind of agent runs on the Kalmido server itself, no computer of your own needed. The person (or the organisation's admin for a team agent) stores an own API key of a model provider (Anthropic first; key sealed, only its last four characters are ever shown, replace or delete it), picks the model from the provider's live list (default Claude Sonnet 5.5, the first Sonnet with a note when the provider no longer offers it) and writes the instructions (prefilled: "Kalmido AI", works with the Kalmido tools only and refuses everything else). Kalmido then calls the model when the agent is asked: chat, @-mention, assignment, comment on a followed task, listening, planned jobs. Tools are exactly the MCP tools with the agent's own token (same rights, scopes and projects as /api/v1; no code, integrations, web or terminal); task, comment, mail and file contents go to the model marked as data. Runs are queue rows of the worker (at most `KALMIDO_SRVAGENT_PARALLEL` at once, one per agent, time and step limits); Stop ends a run within about a second. Tokens per run count into the usage ring and the agent's usage limits, which pause it with the reason. Events made by another agent never start a run.
- Setup (#4670): the dialog *New agent on the Kalmido server* (Settings > Agents, Add agent, Which agent when?) with key, model, instructions and a starter pack of five routines, all on "suggest": morning briefing 07:30, sort the inbox, file receipts and documents, meeting notes into task suggestions, follow up on "waiting on someone" after 5 days. Each can be changed or removed afterwards. The agent's settings show the last runs.
- Instance switch (#4670): admins switch server agents off for the whole server (Settings > Organisation > Agents); allowing them again asks for the account password, both ways are a security alert.
### Changed
- Wide screens (#4553): once the content area is 100rem (about 1600 px) wide, list and detail stand side by side in contacts, clients, quotations, invoices and receipts (list about 40 %, the pair up to 160rem); Esc closes the detail and puts the focus back on its row. The task detail grows with the window, clamp(25.5rem, 30 %, 48rem); a width pulled with the handle still wins, a double click returns to the growing default. Phones and 1440 px stay as they were.
### Security
- Server agents (#4670, Fable review): the run token keeps the owner's address rule (only its own run on the server passes), no provider call while switched off or from a support session, Stop before a run started drops the owner's waiting request only on a personal agent.

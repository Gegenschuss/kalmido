Package 2.1161 (Bündel: Polish Wiki: Handy-Layout - Papierkorb-Namen buchs, Polish Wiki: Lade-, Fehler- und Leer-Zustände aus , Polish Wiki: Seiteninhalt le).
### Fixed
- #6086: Knowledge pages on a phone: in the trash a page's name keeps a line of its own and Restore / Delete go below it (it stood one letter per line); in Select mode the date and the row's "…" leave the row so the page names stay readable; a table in the editor scrolls sideways instead of breaking its headers inside words ("Equipm ent"), the editor's text column keeps its width next to a wide table; with a finger the editor's boxes are as big as the read view's and the row "…", the file buttons, the daily note's arrows and the history's Back are 44 px.
### Changed
- #6088: Knowledge pages use the shared blocks for loading, errors and empty places: a page that cannot be loaded says what failed with Try again and a way back to the pages (also on a phone), a page that does not exist shows the no-access block with the way back, a failed save keeps "Not saved · Try again" in the page's footer until a save works, a failed text search says so instead of "No page matches", the trash, the history, the share dialog and a tag's pages show the shared loading / empty / error states, an empty workspace offers "Create the first page"; about 25 error messages say what did not work first (core.js errText). The shared errorState takes a second button (action).
- #6090: Knowledge page content reads like text: the frontmatter shows as fields (keys as words, dates as the app writes them, the event of minutes as a link) and is one folded line in the editor; a link [[Folder/Page]] shows the page's name (the path as tooltip, in the editor too); "Linked from", search hits and a tag's pages show the name with its folders beside it; a task link in the editor shows its title; a daily note is titled with its date and the folders "journal" / "Templates" show as "Daily notes" / "Templates" in the person's language (the paths stay); a page from a template leaves out the template's empty points and its own frontmatter (its tags stay); a search snippet does not repeat the page's title; the editor's hint no longer shows link syntax.

### Changed
- #5245 Shared core stage 7d: who sees a folder now comes only from the shares on its folder nodes (fs_shares); a group share of a project is a core row on the project node (fs_shares.group_id), a group share of a folder gives a folder role like a person's folder share. folder_people and group_shares are dropped at start after a forward copy and a start check (one-way: older versions no longer start on that database). ### Fixed
- #3911 Moving a task that is already done into the done column (or a rejected task into the rejected column) no longer offers Undo - the move changed nothing, and Undo would have reopened the task. The toast "Moved to section …" stays.

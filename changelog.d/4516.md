### Changed
- #6153: Calendar - a date opened from a repeating event now changes only that date by default ("All dates" must be chosen on purpose, the editor shows that date's times); saving a changed event offers Undo like dragging and deleting (server history, for one date the own change goes again, for all dates the old version comes back).
- #6083: Project settings on a phone - the fields window has one "…" per row instead of three icons (pin, move up, edit); on the computer nothing changes.
### Fixed
- #6086: Knowledge pages on a phone - names in the trash no longer break letter by letter (buttons wrap below), Select keeps the page names readable (date and row menu hidden), tables in the editor scroll sideways instead of cutting headings into syllables, small targets (boxes 20 px, row menu, attachment buttons, day arrows, history back 44 px) fit a finger.
- #6088: Knowledge pages use the shared loading, error and empty states - a page that fails to load offers Try again and Back to the pages, a missing page says so with a way back, a failed save keeps "Not saved" in the footer until a save works, a failed text search no longer looks like "No page matches", error messages say what failed first, an empty space offers "Create the first page".

Package 2.1082 (Bündel: Agenten-Werkzeuge: Anhängen / Abschnitt ersetzen a).

### Added
- #5830: Agents send only the change of a long text: one shared building block (`kalmido/core/mdedit.py`) appends text (at the end or under a heading) or replaces the section below a heading, for knowledge pages, a task's notes and a project's description. New routes `POST /api/v1/wiki/pages/{id}/replace-section`, `POST /api/v1/tasks/{id}/notes/append` / `.../notes/replace-section`, `POST /api/v1/lists/{id}/overview/append` / `.../overview/replace-section`; MCP `wiki_replace_section`, `task_notes_append`, `task_notes_replace_section`, `project_overview_append`, `project_overview_replace_section`. Same rights, lock, history and undo as the whole write; replacing a section needs the version; a heading that is missing (404) or there twice (409) names the headings and writes nothing.
- #5830: Approval cards of these steps show only the lines they add or remove.

### Fixed
- #5830: `wiki_append` is in the MCP toolset `wiki` (it had none; `--toolsets wiki` hid it).

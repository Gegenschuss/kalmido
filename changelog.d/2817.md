Package 2.556 (Bündel: Sammelpaket: Aufgaben ohne Paket (Dispatcher)).
### Added
- New for you: after an update every person sees one dialog with the user sentences of every version since the one they saw last (newest first, a line per version, scrollable; "Older changes" links the change log when the seen version is older than the list reaches). The seen version is kept per person on the server (all devices); a new person starts at the current version; Settings > Help switches it off. The sentences come from static/whatsnew.json, which the release train writes (#4685)
- Recurring tasks: the completed copy keeps a read-only note of its subtasks when it was ticked ("3 of 5 subtasks done" with the titles ticked / open), in the task panel and the API for people (never for agents, events or webhooks; not in projects with the lock); the original's subtasks are reset as before, Undo removes the copy with its note (#4583)
### Changed
- Sidebar: the group of lists is always visibly called "Lists" (folded it showed only an arrow and a number); its buttons say "Sort lists" / "New list" (#4661)
- Sidebar: the fixed row "Notes" under Plan is gone on the computer and in the phone menu; the Notes area, the list Notes and quick notes stay (#4665)
- Agent chat: stopping a running answer is Shift+Esc; plain Esc no longer stops it and does what it does otherwise (Ctrl+C and Cmd+. stay) (#4666)
- Agent band over a list follows its own width instead of the window: the name before the state, boxes at least 8rem, the rest as "+N" that opens Agents, only the dots when very narrow (#4663)
- CI: the full run plans exactly 20 shards (hard ones included, tools/shards.py --total) with a 60 min limit instead of up to 28 that queued; the dead job/** trigger and the [release] group are gone (#4388)
### Fixed
- Two styles off the type scale (failed comment note, touch hint in tables) red the scale check on main (#4662)
### Tests
- Operator console: deleting an account with records kept by law after its retention export works without a person (the suspected crash does not happen) (#4672)

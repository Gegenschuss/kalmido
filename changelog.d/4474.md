### Added
- #4550: Find people - "Invite by link": a person creates a one-time link with QR code (valid 14 days, copy / share, an own note) for someone without an account; whoever opens it registers a private account (with e-mail: confirmed by a link; without e-mail sending: name + password, no address stored) and is connected with the inviting person, who gets a news item. A signed-in person opening the link is asked "Connect with X?". Open links are listed and can be withdrawn (undo for 24 hours). Server switch Settings > Server > Sign-in "People without an account register with an invitation link" (on by default only when anyone may register). Limits: 20 open links per account, 10 new per day, rate limits per client address; not for agents. Security review findings (unconfirmed address without e-mail, approval after the inviter was blocked, withdraw during redemption, inviter named in the mail) fixed.
### Changed
- #4280: Start size - rarely used dialogs and modules load on first use instead of at the start (project, share, folder settings, client, calendars, custom field, time entry, habit, agent plans and proposal cards, approval links, tags overview, organisation export, photo metadata, encryption scope, parts of the settings): start JavaScript 1,018 KB -> 923 KB gzip, start scripts 139 -> 130. Nothing was shortened, only moved.
